# L'atelier Cuisine Française — サンプルサイト

フレンチレストラン向けのホームページ制作サンプル（営業提案用）。
既存サイトを運用中の店舗へ、リニューアル後のイメージを提示する目的で制作。

> **本サイトは架空のデザインサンプルです。**
> 店名以外の人物名・住所・電話番号・メニュー・価格・経歴はすべて架空のものであり、
> 実在の店舗・人物とは関係ありません。各ページのフッターにも同じ注記を入れています。

---

## ページ構成（4ページ）

| ファイル | 内容 |
| --- | --- |
| `index.html` | TOP。ヒーロー／コンセプト抜粋／料理6品／コース誘導／**日替わりランチの帯**／店内／**ACCESS（`#access`）** |
| `concept.html` | シェフのメッセージ、こだわり3項目（素材・火入れ・もてなし）、料理長プロフィール |
| `menu.html` | アラカルト。カテゴリー絞り込み付き（冷前菜〜ドリンクの7カテゴリー） |
| `course.html` | **日替わりランチ（`#daily-lunch`）**、ランチ3種・ディナー3種のコース、記念日/貸切のご案内、予約について |

### 価格帯の見せ方

気軽に入れる店であることを伝えるため、価格帯を2段構えにしています。

- **日替わりランチ 1,000〜1,500円**（平日 11:30〜14:00 限定・予約不要）… TOP に専用の帯、`course.html#daily-lunch` に詳細
- **コース** … ランチ 4,200円〜／ディナー 8,800円〜

「平日限定・数量限定」という条件を添えることで、コース価格との差に説明がつくようにしています。
不要であれば `.daily` ブロックごと削除すれば元の構成に戻ります。

ACCESS は独立ページを作らず、TOP 下部に集約しています（ナビの ACCESS は `index.html#access` へ）。

## 使い方

ローカル確認は静的サーバー経由を推奨します（`file://` でも動作しますが、相対パスの都合上サーバー推奨）。

```bash
python3 -m http.server 8788
```

`http://localhost:8788/` を開いてください。ビルド不要、そのまま任意のサーバーへアップロードできます。

## 技術構成

- **依存ライブラリなし**（バニラ JS + CSS）。CDN 障害やオフラインでも表示が壊れません
- Web フォントのみ外部読み込み（Google Fonts: Cormorant Garamond / Shippori Mincho / Zen Kaku Gothic New）。読み込めない場合は端末の明朝・ゴシックにフォールバックします
- スマホファースト。`clamp()` による流動タイポグラフィで PC まで対応
- `prefers-reduced-motion` 対応、`.no-js` フォールバックあり（JS 無効でも全コンテンツが見えます）

### アニメーション（parade.kyoto を参考に再現）

参考サイトの実装（GSAP + ScrollTrigger + Swiper）を解析し、同等の見え方を依存なしで実装しています。

| 演出 | 仕様 |
| --- | --- |
| ローディング | ロゴのフェードイン＋ゴールドのプログレスバー、`load` 後にカーテンが消える |
| 見出しの文字送り | 1文字ずつ `opacity 0→1` / `translateY→0` / `blur(9px)→0`、`2.1s cubic-bezier(0.19,1,0.22,1)`、25〜30ms ずつ遅延。スクロールで戻ると巻き戻る |
| 画像リビール | `scale(1.2)→1` を 2秒かけて。ゆっくり寄りが解けるズーム |
| ブロックリビール | `translateY(56px)→0` + フェード、`data-delay` で段差をつける |
| KV | 背景4枚を5.2秒ごとにクロスフェード＋常時スローズーム |
| カスタムカーソル | PC（1025px 以上・hover 可）のみ。追従は lerp 0.3、リンクで拡大、`data-cursor-text` でラベル表示 |
| その他 | 帯状のマーキー、ヘッダーの自動隠し、フルスクリーンのドロワー |

スクロール判定は `IntersectionObserver` ではなく `requestAnimationFrame` + `getBoundingClientRect` で実装しています。
IO はタブ／ペインが非表示のとき発火せず、コンテンツが不可視のまま残る事故があるためです。

## ファイル構成

```
.
├── index.html / concept.html / menu.html / course.html
└── assets/
    ├── css/style.css      … 全ページ共通
    ├── js/main.js         … 全ページ共通
    └── img/
        ├── favicon.svg
        ├── dish/          … 料理11点（512×512 に正方形トリミング）
        ├── scene/         … 外観・内観・シェフ（1536px と 960px の2サイズ、srcset で出し分け）
        └── src/           … 支給素材の原本（コラージュ2点・シーン3点）。公開には不要
```

### 画像について

支給素材のうちコラージュ2点は、料理ごとに分割して個別画像として使用しています。

- `grid6.jpg`（3×2）→ poisson / carpaccio / roti / foiegras / veloute / mille
- `grid5.jpg`（上2＋下3）→ canard / saintjacques / filet / sorbet / terrine

外観・内観写真に写り込んでいる「L'atelier Cuisine Française」の看板にあわせ、店名をそのまま採用しています。
サイト上では「ラトリエ キュイジーヌ フランセーズ」のカタカナ表記を併記しています。

## 差し替えポイント

実店舗向けに転用する場合、以下を書き換えてください。

- 店名・カタカナ表記 … 各 HTML の `.header__logo` / `.footer__logo` / `.loading__logo` / `<title>` / `<meta>`
- 住所・電話・営業時間・定休日 … `index.html` の `#access` セクション、および全4ページのフッターとドロワー
- 地図 … `index.html` の `#access` 内はインライン SVG の略地図。Google マップの iframe に差し替える場合は `.access__map` の中身を入れ替え（`.access__map iframe` のスタイルは用意済み）
- 配色 … `assets/css/style.css` 冒頭の `:root` 変数（`--gold` などを変えるだけで全体の印象が変わります）
